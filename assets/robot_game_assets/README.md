### Robot game asset pack (placeholder art)

All art is procedural placeholder art generated by the scripts in `tools/`. Treat it as production-ready only for prototyping; replace with hand-drawn art later while keeping the same sizes and layouts.

### Scale and grid

- Everything is exported at **2x** of a native pixel grid (characters drawn on 2x2 blocks, like the hero).
- **Tiles: 64x64 px** (32x32 native). The hero robot occupies about one tile.
- **Character cells: 96x96 px**, feet/pivot at **(48, 78)** for every character sheet.
- Props: `anchor` in the atlas JSON = ground contact point. Y-sort sprites and props by anchor y.

### Folders

- `characters/hero` - TV-head robot: idle, walk, attack, hurt (4 dirs), death, hold item, jump (4 dirs).
- `characters/robot_npcs` - Scrap, Radio, Merchant, Gardener: idle/walk (4 dirs), talk.
- `characters/animals` - deer, wolf, fox, bear, squirrel, hedgehog, hare, partridge: idle/walk (4 dirs) + one action each (side view).
- `characters/spirits` - the same animals + 6 people as spirits (translucent PNGs) with extra `appear_down` / `vanish_down`.
- `characters/humans_living` - the 6 people as normal avatars (for the "avatar view").
- `biomes/<biome>` - per biome:
  - `<biome>_tiles.png/.json` - base tile variants, animated tiles (4 frames, ~4 fps) and **corner-Wang transition sets** (16 tiles each).
  - `<biome>_props.png/.json` and `props/*.png` - all objects from the concept scenes, with anchors.
  - `<biome>_demo_map.png` - a map built only from that pack's tiles and props (seam check).
- `biomes/shared` - animated spawn pad (4 frames) and its light beam (draw after the pad, alpha or additive).
- `concept_art` - the composed scenes for mood reference.
- `tools` - the Python generators; re-run to tweak colours/shapes and re-export.

### Corner-Wang transition sets

Each set is named `upper__over__lower` and has 16 tiles in index order:

`index = NW*8 + NE*4 + SW*2 + SE*1`, where a bit is 1 if that corner is the upper terrain.

- Index 0 = all lower terrain, index 15 = all upper terrain (use the base variants for those for more variety).
- **Godot 4**: TileSet -> Terrains -> mode *Match Corners*; paint each tile's 4 corner bits from its index.
- **Tiled**: Wang set of type *Corner*; assign the two colours per corner the same way.

### Known limits

- Props were cut out of the concept scenes, so some carry scene-specific context (e.g. rooftops include their submerged walls, towers include their sand mound).
- Large structures (rooftops, decks, gorge) are props rather than tiles; for real levels you may want them as tiles too.
- No collision data is included; define it in the engine.
