# Game concept

This folder is the game's concept document. It is the primary source for what the game should become: design, architecture, levels, and art all grow from it. When code or another document disagrees with the concept, the concept wins, or the concept is changed first and deliberately.

The concept was written by Andrei on 2026-11-08 and is kept in his words. Open questions stay open here until he decides them; do not settle them in code.

| Document                               | What it covers                                                     |
| -------------------------------------- | ------------------------------------------------------------------ |
| [pitch.md](pitch.md)                   | The one-paragraph pitch and the project's status at the pitch date |
| [world-and-lore.md](world-and-lore.md) | The virtual world, avatars, robots, and the two perceptions        |
| [gameplay.md](gameplay.md)             | The hero's move set, proposed mechanics, and what is undecided     |
| [characters.md](characters.md)         | The hero, robot NPCs, and human and animal avatars                 |

The placeholder art that matches this concept lives in [assets/robot_game_assets/](../../assets/robot_game_assets/).
